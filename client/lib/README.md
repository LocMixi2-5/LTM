# Thư mục Thư viện Client (client/lib)

Dự án Client sử dụng JavaFX 17+. Để biên dịch và chạy dự án:

1. Tải **JavaFX Windows x64 SDK 17+** (ví dụ: `javafx-sdk-17.0.13`) từ [Gluon](https://gluonhq.com/products/javafx/).
2. Giải nén thư mục SDK vào `client/lib/javafx-sdk-17.0.13/`.
   - Đảm bảo đường dẫn `client/lib/javafx-sdk-17.0.13/lib/javafx.controls.jar` tồn tại.
3. Chạy `compile.bat` để biên dịch hoặc `run_client.bat` để khởi động game.
